# 歌词设置

控制歌词搜索、格式和写入行为。

## 歌词模式

选择搜索歌词时优先获取的歌词格式：

- **逐行歌词**：传统的逐行 LRC 格式。
- **逐字歌词**：包含逐字时间轴的歌词。
- **增强型逐字歌词**：包含逐字时间轴和更多元数据的歌词。
- **TTML**：TTML 格式歌词（Timed Text Markup Language）。

## 翻译与罗马音

- **罗马音**：开启后，搜索歌词时请求罗马音内容（适合日语歌曲）。
- **翻译**：开启后，搜索歌词时请求翻译内容。
- **仅下载翻译歌词**：需先开启“翻译”。有译文的歌词行使用译文，缺少译文的行保留原文。

如需调整已有歌词的行顺序，在单曲编辑页打开 **歌词选项 → 歌词整理 → 按句排序**。详见 [歌词整理](../single-song.md#歌词整理)。

## TTML 信息保留

输出 TTML 时，会保留源数据中受支持的演唱者、段落时间、语言、head 元数据、逐词音译和多音节 Ruby 注音。Ruby 时间会随歌词偏移同步调整；缺失边界会参考相邻音节和词时间补齐。正文时长不随偏移改变。

LRC 无法保留演唱者、段落和 Ruby 等 TTML 专属结构；逐字 LRC 可保留音译时间戳。解析和重写不保证保留任意 XML 结构，API5 插件可通过扩展字段提供受支持的信息。

## 注意事项

修改歌词模式、罗马音或翻译设置后，已有的搜索结果 **不会自动刷新**。需要重新搜索歌词才会使用新配置。

这些设置也不影响已经保存到音频文件中的歌词。
