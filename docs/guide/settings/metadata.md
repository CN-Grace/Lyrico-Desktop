# 元数据处理

控制元数据文本处理和显示相关的设置。

## 中文文本转换

"中文文本转换"会应用于搜索到的文本元数据和歌词。ID、日期、数字、URL 和封面不会受转换影响。

可选模式：
- 不转换
- 简体转繁体
- 繁体转简体

## 移除空行

开启后，保存歌词和其他多行文本字段时会自动删除其中的空行。

## 非歌词内容过滤

在“歌词整理”中选择“移除非歌词内容”时，使用这些规则清理作词、作曲、来源等非歌词行。

过滤规则在 `设置` → `元数据处理` → `非歌词内容过滤规则` 中维护。规则按关键词匹配，不区分大小写。歌词行包含任一关键词就会被移除；逐字歌词按整行文本判断。

常见过滤示例：`作词：`、`作曲：`、`编曲：`、`来源` 等。

## 艺术家拆分

**"艺术家拆分规则"** 影响艺术家视图的归类方式。开启后，Lyrico 会将包含多个艺术家的歌曲分别在艺术家中归类。

可以在拆分设置中配置：
- 额外的分隔符（如 `feat.`、`&`、`,` 等）。
- **不拆分明细**：某些艺术家名称不应被拆分（如艺术家名本身就包含分隔符的情况）。

修改分隔符或白名单后，通常需要点击 **"重建艺术家索引"** 才会完全生效。

## 编辑字段

进入 **设置 → 元数据处理 → 编辑字段**，统一管理内置字段和自定义标签。

- 长按字段拖动，调整编辑页中的顺序；右侧开关控制显隐。
- 回放增益的菜单中可选择 **管理字段**，调整组内字段的顺序和显隐。组开关与成员开关分别保存。
- 选择 **查看歌曲**，查看该字段“已填写”或“未填写”的歌曲。
- 点击顶栏恢复默认按钮，可重置字段配置；不会修改歌曲数据。

配置用于单曲编辑、批量编辑和批量匹配。关闭字段不会清空文件中已有的标签。

### 自定义标签

点击右上角 **“+”**，从音乐库已发现的标签中选择，或输入标签键（如 `SOURCE`）。键名会去除首尾空白并转为大写；不能重复、包含换行或超过 64 个字符。

自定义标签可通过菜单删除。删除只移除配置，不会删除歌曲中的标签数据。

封面查询需要读取文件，读取失败的歌曲不会被计入“未填写”。每个查询标签页最多显示 500 首歌曲。

## 配置字符映射

用于批量重命名时，将文件名中的特定字符替换为其他字符。

在字符映射页中，点击字符可修改其替换规则。每个字符可以映射到不同的替换值。常见用法例如将 `/` 替换为 `-`，或将 `:` 替换为 `_` 等不适合作为文件名的字符。
