# 资料库与文件夹

管理 Lyrico 扫描的音乐文件夹，以及音乐库的维护操作。

## 文件夹管理

进入路径：`设置` → `扫描设置` → `文件夹管理`。

文件夹管理页包含"文件夹"和"歌曲"两个标签页，分别用于查看文件夹树结构和该范围下的歌曲列表。

### 添加文件夹

点击添加按钮，在系统目录选择器中选中存放音乐的文件夹并授权。添加后，Lyrico 会自动开始扫描该文件夹。

如果已开启 `设置` → `扫描设置` → `不扫描 60 秒以下音频`，时长不超过 60 秒的音频会被跳过，适合过滤提示音、短片段和采样文件。

### 刷新文件夹

"刷新文件夹"会重新扫描对应文件夹。适合以下场景：
- 在系统文件管理器中新增了音频文件
- 删除了部分音频文件
- 用其他工具修改了文件的标签

### 隐藏与显示文件夹

**隐藏文件夹**：隐藏该文件夹及其子文件夹中的歌曲。隐藏后歌曲不出现在歌曲列表、艺术家列表、专辑列表和本地搜索结果中。

**显示文件夹**：恢复显示之前隐藏的文件夹及其歌曲。

隐藏不会删除文件，也不会移除文件夹记录。适合临时排除某些文件夹（如铃声、播客）的场景。

### 移除文件夹

从 Lyrico 中移除此文件夹，并清除音乐库里的对应歌曲记录。本地音频文件不会被删除。之后仍可重新添加此文件夹。

### 操作对比

| 操作 | 本地文件 | 文件夹记录 | 歌曲是否显示 |
|------|----------|------------|-------------|
| 隐藏文件夹 | 保留 | 保留 | 不显示，可再次显示 |
| 移除文件夹 | 保留 | 移除 | 不显示，需重新添加 |

## 艺术家海报文件夹

艺术家视图（列表和详情页）和单曲编辑页都优先使用属于这位艺术家的 **内嵌图片**。归属看图片的**描述**：描述里写的是哪位艺术家，这张图就归谁；没写描述的旧图片按"整首歌只有一位艺术家"来认定。某位艺术家没有可用的内嵌图片时，Lyrico 才会为这位艺术家到"艺术家海报文件夹"里按 **文件名** 查找。进入路径：`设置` → `扫描设置` → `艺术家海报文件夹`。

**添加文件夹：** 点击右上角的添加按钮，在系统目录选择器中选中存放海报的文件夹并授权。授权后 Lyrico 会立即读取其中的海报文件。

**海报命名规则：**

| 文件名 | 匹配的艺术家 |
|--------|-------------|
| `艺术家.jpg` | 名称完全一致的艺术家 |
| `艺术家_live.jpg` | 名称完全一致，且文件名以 `_` 接后缀 |
| `AC_DC.jpg`、`AC-DC.jpg`、`AC／DC.jpg` 或 `ACDC.jpg` | 名称中含文件名不能出现的字符（`\ / : * ? " < > \|`）的艺术家，如 `AC/DC` |

支持 JPG、JPEG、PNG、WebP 和 MP4（取视频首帧）。只查找所选文件夹中的文件，不会递归子文件夹。

**多个文件夹：** 按添加顺序依次查找，找到即可用；同一文件夹内优先使用与艺术家名完全一致的完整文件名，其次才是带后缀的变体。

**匹配状态：** 文件夹列表中会显示该文件夹的海报总数，以及其中命名匹配到库内艺术家的数量。如果数量为 0，通常说明文件名与艺术家名不一致，可展开文件夹逐个核对。

**移除文件夹：** 只是停止使用该文件夹中的海报，不会删除本地文件。移除后不再重新授权，需要时重新添加即可。

## 扫描设置

`设置` → `扫描设置` 中包含以下选项：

- **文件夹管理**：管理已添加的音乐文件夹，入口同上。
- **艺术家海报文件夹**：管理艺术家海报文件夹，入口同上。
- **不扫描 60 秒以下音频**：开启后跳过时长 ≤ 60 秒的音频文件。
- **歌词索引**：开启后会在扫描时建立歌词索引，用于本地歌词搜索。开启会增加扫描耗时；开关状态改变后，已有歌曲需要重新扫描才会生效。
- **回放增益参考响度**：计算 ReplayGain 时使用的目标响度，默认 **-18 LUFS**。可在 **-23 LUFS（EBU R128）**、**-18 LUFS（默认）**、**-14 LUFS（流媒体常用）** 三个预设中选择，或输入 **-60 到 0 LUFS** 之间的自定义值。该设置会影响单曲编辑、专辑和批量计算回放增益的结果，详见 [单曲编辑 ReplayGain](./single-song.md#replaygain)。
- **回放增益峰值类型**：选择写入 ReplayGain 峰值标签的测量方式。默认的 **采样峰值** 与传统 ReplayGain 峰值语义一致；**真实峰值** 使用过采样插值估计模拟重建后的峰值。两者都以 1.0 表示数字满刻度，但解码后的压缩音频即使使用采样峰值也可能大于 1.0。该设置同样作用于单曲、专辑和批量计算。

## 文件夹权限问题

如果出现以下情况，Lyrico 会自动清理对应的音乐库记录并刷新索引：
- 文件夹权限丢失（如系统回收了存储权限）
- 文件夹被删除或移动
- 数据库中的歌曲在设备上已不存在

如果遇到"部分文件无法访问"的提示，可以尝试：
1. 进入 `文件夹管理`，移除受影响的文件夹。
2. 重新添加该文件夹并授权。
