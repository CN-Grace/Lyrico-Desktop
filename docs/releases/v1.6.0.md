# Lyrico 1.6.0（Windows x64 桌面版）

Lyrico 的 **Windows 原生桌面版**：从原 Android 版完整移植到 Kotlin/JVM + Compose Multiplatform，界面上仍是熟悉的 Miuix 风格，数据格式与安卓版同源（同一套 Room 结构与偏好键）。适用于本地音乐库的标签编辑、歌词处理、封面管理与批量任务。

## 下载哪个

| 文件 | 大小 | 说明 |
|---|---|---|
| `Lyrico-1.6.0.msi` | 140.1 MiB | **推荐**。Windows 安装包，**自带运行时**，不需要机器上装 Java；带开始菜单与快捷方式，可选安装目录 |
| `Lyrico-1.6.0-windows-x64-portable.zip` | 115.0 MiB | 便携版：解压后双击 `Lyrico.bat`。**需要机器上有 Java 21+**（`JAVA_HOME` 或 `PATH`），数据放在解压目录下的 `data/`，整体可搬走/备份 |

应用数据目录默认**便携优先**：程序目录可写时用 `<程序目录>\data`，不可写（例如装在 `Program Files`）时回退到 `%LOCALAPPDATA%\Lyrico`；也可用 `-Dlyrico.data.dir=<路径>` 显式指定。

## 本版要点

这是移植收口后的第一个桌面正式版，主要工作：

- **功能补齐**：曲库（歌曲/专辑/艺人三视图）、专辑与艺人详情、设置簇（外观/扫描/歌词/搜索/备份/清理缓存）、本地搜索、批量重命名、批量编辑与字符映射、文件夹管理、插件管理与插件配置、批量任务列表与详情、关于页与开源许可页。
- **语言切换实时生效**：设置里选语言后整个界面（含零食条提示与插件字符串）立即切换，无需重启。
- **ReplayGain**：通过随包的 `ffmpeg` 边车解码测量响度（见下方许可说明）。
- **导出/导入设置**：JSON 备份，含语言等外观偏好。
- **打包**：MSI 安装包、自带运行时的 app image、便携 zip 三件齐备，原生库（TagLib / libebur128 / quickjs-ng）与 ffmpeg 边车按运行时探测的布局随包。

## 第三方组件与许可

应用内「关于 → 开源许可」列出全部组件；`THIRD_PARTY_NOTICES.md` 与包内 `LICENSE.txt` 为随包声明。要点：

- **FFmpeg（LGPL v3）**：`ffmpeg/windows-x64/ffmpeg.exe` 是 BtbN/FFmpeg-Builds 的**未修改** LGPL 构建，作为**独立进程**（边车）调用，许可证文本随二进制一起分发（同目录 `LICENSE.txt`）。它只用于响度分析；缺少它时应用仍可正常使用，仅该功能不可用。固定版本与哈希见仓库 `docs/third-party/ffmpeg-lgpl.md`。
- **TagLib**（LGPL-2.1 或 MPL-1.1）、**libebur128**（MIT）、**quickjs-ng**（MIT）：静态/动态链接见上述清单，含许可证文本位置。
- 其余依赖（Compose Multiplatform、Miuix、Koin、Room、OkHttp、Coil 等）均为 Apache-2.0，版本号由构建期从 `gradle/libs.versions.toml` 生成。

## 已知限制（如实列出）

1. 桌面端没有系统「返回手势」，各页用自带的返回/关闭控件。
2. 「用其它程序打开」只走系统默认关联程序；安卓那种「指定播放器包名/选择器」没有等价物。
3. 液态玻璃悬浮栏的视觉效果未移植（毛玻璃与纯色保留）。
4. 主题键色：默认项不跟随壁纸取色；薄荷模式下键色不生效。
5. 命令行传入的文件暂未接到编辑页（双击关联文件只会打开曲库首页）。
6. 部分英文文案的复数形式未处理（如 `1 folders found`）。
7. 开源许可清单为手工维护 + 构建期生成的混合，若上游依赖新增而清单未同步，页面可能滞后。

完整记录（含每条缺口的出处、测试口径与真窗口证据索引）见仓库 `PLAN.md` 的 P5/P6 各节。
